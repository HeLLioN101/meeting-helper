# Meeting Helper

**Meeting Helper** is an AI-powered tool that boosts meeting productivity by combining real-time transcription and intelligent question-answering features. It allows seamless interaction during meetings by offering live transcriptions and instant responses to user queries based on the conversation and uploaded documents. 

This application is designed for professionals who need a reliable and efficient way to handle meeting notes, get real-time summaries, and automate documentation processes.

---

## 🚀 Features

- **Real-time Transcription:** Captures meeting audio in real-time and transcribes it accurately.
- **AI-Powered Q&A:** Get instant answers and summaries during meetings using Google Gemini AI.
- **Document Upload:** Upload and process PDF, DOCX, and PPTX files for contextual Q&A.
- **Cross-Platform Compatibility:** Supports Windows, Ubuntu, and most Linux distributions.
- **Intuitive User Interface:** A user-friendly PyQt5 interface for easy navigation and interaction.

- Python 3.6 or higher.
- Pip package manager.

1. **Clone the repository:**

   cd meeting-helper
2.**Install dependencies:**
   ```bash
    pip install -r requirements.txt
```
